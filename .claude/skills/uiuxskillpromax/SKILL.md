# UI/UX Pro Max — Design Reference Library

Local, offline reference library imported from [uiuxskillProMax](https://github.com/yuanfu8899/uiuxskillProMax) (generated by the [UI/UX Pro Max Skill](https://ui-ux-pro-max-skill.nextlevelbuilder.io/)). Use it to ground design decisions on this site instead of guessing at styles, colors, or icons from scratch.

## What's here

- **`js/style-data.js`** — structured data (JSON-like) for 58 design styles: category, keywords, primary/secondary/effect colors, best-for / avoid use cases, accessibility rating, dark-mode support, and framework compatibility. Read this directly rather than opening the HTML when you just need the metadata for a style.
- **`refstyles/NN-style-name.html`** — a live, self-contained coded example for each of the 58 styles (e.g. `refstyles/03-glassmorphism.html`, `refstyles/28-data-dense-dashboard.html`). Open one to see real markup/CSS you can lift patterns from.
- **`uiuxpro_styles.html`** + **`css/main.css`** + **`js/style-app.js`** — the browsable gallery UI for the style library (filterable by category, e.g. general / landing page / BI dashboard).
- **`js/colors-data.js`** — 96+ industry-specific color palettes as structured data (primary, secondary, cta, background, text, border hex values + notes). Includes **"Medical Clinic"**, **"Healthcare App"**, and **"Mental Health App"** entries directly relevant to this site's domain.
- **`uiuxpro_colors.html`** + **`js/colors-app.js`** — browsable color palette gallery (random-pick or browse-all modes).
- **`uiuxpro_icons.html`** — curated Lucide icon usage reference and best practices.

## How to use it

1. **Picking a visual style**: grep/read `js/style-data.js` for candidates matching the page's purpose (e.g. `landing page`, `dashboard`, `healthcare`), then open the matching `refstyles/*.html` file to see the real implementation before adapting it into this site's actual markup.
2. **Picking colors**: grep `js/colors-data.js` for `"Medical Clinic"` or `"Healthcare App"` (or another relevant industry) to get a ready-made, accessible hex palette instead of inventing one.
3. **Picking icons**: check `uiuxpro_icons.html` for Lucide icon names and usage patterns already vetted for clarity/consistency.
4. Treat this library as reference material only — never copy a `refstyles/*.html` file wholesale into the live site; adapt the relevant CSS/structure into this project's actual pages and existing branding (logos in the repo root: `saba-medical-logo.png`, `midmark-logo.png`, `sami-logo.png`).
